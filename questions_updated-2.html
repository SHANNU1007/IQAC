IQAC Central Server Setup
Connect all PCs to the central server running on Admin PC
How it works:
  1. The Admin PC runs C:\Users\WINDOWS\Desktop\projects junaid\server\START_SERVER.bat
  2. All other PCs open their browser and go to
    http://10.1.16.10:3000/
  3. All data automatically syncs to the Admin PC in real time
  4. Admin monitors everything at http://10.1.16.10:3000/
The IP address of the Admin PC running the IQAC server. Default port is 3000.
